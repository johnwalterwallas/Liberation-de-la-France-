# La Libération de la France — V1

Prototype statique pour GitHub Pages.

## Contenu
- carte Leaflet interactive ;
- 8 jalons documentaires ;
- fiches en panneau latéral ;
- timeline du 6 juin 1944 au 8 mai 1945 ;
- animation temporelle ;
- responsive mobile / tablette / ordinateur ;
- données séparées dans `data/battles.json`.

## Mise en ligne
Déposer le contenu du dossier dans un dépôt GitHub puis activer GitHub Pages sur la branche `main`, dossier `/root`.

## V2 recommandée
Ajouter les cartes militaires historiques, les sources individuelles, les photos d'archives, les tracés animés des axes de progression, les filtres, FR/EN et les fiches complètes des poches de l'Atlantique.
